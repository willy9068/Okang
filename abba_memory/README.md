# 오캉과 엄마: 아빠의 기억 — 데모

아버지의 기억 속 1990년, 어머니를 처음 만나 작은 가게를 확장하는 머지 퍼즐 스토리 게임 데모입니다.
기준 문서: `../오캉과엄마_아빠의기억_데모_개발가이드_클로드코드.md`

## 실행

- **개발본**: `src/index.html`을 브라우저로 엽니다. 파일을 더블클릭해서 열어도 됩니다(`file://`).
  - 브라우저 크기를 세로로 좁히면 휴대폰 화면처럼 보입니다. PC에서는 세로 창이 가운데에 뜹니다.
- **제출본**: `dist/abba_memory_demo.html` **한 파일**. 그림·코드가 모두 들어 있어서 이 파일만 어디에 옮겨도 열립니다 (약 1.3MB).
  - 다시 만들기: `python tools/build_single.py` (Pillow 필요: `pip install pillow`). 그림이나 코드를 고친 뒤에는 꼭 다시 만드세요.
  - `assets/`에 있는 그림만 WebP로 줄여 넣고, 없는 그림은 게임이 대신 그립니다 (빌드가 어떤 그림이 없는지 알려 줌).

### 휴대폰에서 해 보기
1. `dist/abba_memory_demo.html`을 카카오톡(나에게 보내기)·메일 등으로 휴대폰에 보냅니다.
2. 받은 파일을 **크롬 또는 사파리로** 엽니다. 메신저 안의 미리보기 창에서는 저장(이어하기)이 안 될 수 있습니다.
3. 열리지 않으면 파일을 '내 파일'(안드로이드) / '파일' 앱(아이폰)에 저장한 뒤 브라우저로 엽니다. 기종마다 방법이 달라서 직접 확인이 필요합니다.

- 휴대폰: 주소 끝에 `?debug`를 붙이면 왼쪽 위에 `D` 버튼이 생깁니다

## 대사·UI 편집기 (2026-10-29)

**`편집기_켜기.bat`을 더블클릭**하면 검은 창이 뜨고, 브라우저에 편집기가 열립니다 (Python 3 필요). 검은 창을 닫으면 편집기가 꺼집니다.

| 탭 | 고칠 수 있는 것 |
| --- | --- |
| 화면 배치 | HUD, 확장 버튼, 손님·접시 칸, 가게 그림, 보드, 안내 문구 줄, 대화창, 인물 그림, 선택지 버튼, 간판 글씨 자리. **오른쪽 미리보기에서 상자를 끌면 옮겨지고, 오른쪽 아래 네모를 끌면 크기가 바뀝니다.** 숫자로도 고칠 수 있습니다 |
| 화면 문장 | 이름표(나·태자), 손님 이름, 조작 안내 3문장, 버튼·안내·끝 화면 문장, 간판 글씨 |
| 대사 | 도입·스토리 1·스토리 2·마무리의 대사 줄과 선택지(보기·태자 반응·아버지 속마음). 줄 추가·삭제·순서 바꾸기. 줄을 누르면 미리보기에 그 줄이 보입니다 |

- **저장**을 누르면 `src/ui_text.js`(배치·문장)와 `src/story_data.js`(대사)가 바뀝니다. 바뀌기 전 파일은 `tools/editor_backup/<날짜_시각>/`에 남습니다 (저장소에는 올리지 않음).
- "저장 안 한 변경 버리기"는 마지막으로 저장한 상태로 되돌립니다.
- **줄 바꿈 · 문장 기호 (2026-10-29)**: 대사·튜토리얼 입력칸에서 **Enter**를 누르면 게임에서도 그 자리에서 줄이 바뀝니다. 탭 위 **글자 도구**로 고른 칸에 `↵ 줄 바꿈` `.` `,` `?` `!` `…` `~`를 넣고, `“ ”` `‘ ’`는 고른 글자를 감쌉니다. **'문장마다 줄 나누기'**는 마침표·물음표·느낌표·말줄임표 뒤 띄어쓰기를 줄 바꿈으로 바꿉니다. 입력칸 아래에 **게임 화면에서 몇 줄인지** 나오고 넘치면 빨갛게 표시됩니다 (대화창·튜토리얼 3줄, 선택지 2줄. 대화창 4번째 줄은 모서리 장식과 겹침)
- 편집기 안의 게임(미리보기)은 진행을 저장하지 않습니다. 실제 플레이는 `src/index.html`로 합니다.
- 저장할 때 빈 대사·빈 선택지 칸이 있으면 저장하지 않고 이유를 알려 줍니다.
- **저장한 뒤 게임에서 확인하기**: `src/index.html`을 새로고침(F5)합니다. 개발본은 열 때마다 스크립트·그림을 새로 읽으므로(2026-10-29) 저장한 값이 바로 보입니다. 이 변경 전에 열어 둔 브라우저라면 **한 번만 Ctrl+F5**. 고친 곳이 그 화면에 있어야 보입니다.
  - 타이틀·끝 화면 → D키 디버그 패널의 **'타이틀 보기' / '끝 화면 보기'**
  - 스토리 장면·대화창·간판 글씨(마무리) → D키 **'스토리 보기'** (간판 글씨는 `ending`)
  - 손님·접시·"내기" 글자 → 머지 화면 (내기 버튼은 접시에 요리가 다 모였을 때만)
- **편집기 코드를 고친 뒤에는** 검은 창을 닫고 `편집기_켜기.bat`을 다시 켜야 새 코드로 저장됩니다.

## 수치 고치기

게임 수치는 `src/data.js`에 있습니다. 보드 칸 수, 단계 이름, 생성기 위치, 시작 재료, 주문(단계·보상·2개짜리 확률) `orders`, 확장 비용 `expand.costs`, 글자 속도 `story.charsPerSec`, 스토리별 배경 `story.bg` 등.
화면 배치·문장은 `src/ui_text.js`, 대사는 `src/story_data.js`입니다 (편집기로 고치는 것을 권장).
보드 칸 수를 바꾸면 저장된 진행은 자동으로 버리고 새로 시작합니다.
