# 오캉과 엄마: 아빠의 기억 — 데모

아버지의 기억 속 1990년, 어머니를 처음 만나 낡은 가게를 복구하는 머지 퍼즐 스토리 게임 데모입니다.
기준 문서: `../오캉과엄마_아빠의기억_데모_개발가이드_클로드코드.md`

## 실행

- **개발본**: `src/index.html`을 브라우저로 엽니다. 파일을 더블클릭해서 열어도 됩니다(`file://`).
  - 브라우저 크기를 세로로 좁히면 휴대폰 화면처럼 보입니다. PC에서는 세로 창이 가운데에 뜹니다.
- **제출본** (6일차): `dist/abba_memory_demo.html` 한 파일 (아직 없음)

## 조작

| 동작 | 결과 |
| --- | --- |
| 생성기(노란 테두리 칸) 탭 | 가장 가까운 빈 칸에 1단계 재료 |
| 아이템을 끌어 같은 종류·같은 단계 위에 놓기 | 다음 단계로 합쳐짐 (끄는 동안 합칠 수 있는 칸에 노란 점선) |
| 다른 아이템 위에 놓기 | 자리 바꿈 |
| 아이템 탭 | 이름과 다음 단계 안내 |
| 아이템 길게 누르기 (0.6초) | 삭제 (빨간 원이 다 차면) |

## 디버그 패널

- PC: **D키**로 열고 닫기
- 휴대폰: 주소 끝에 `?debug`를 붙이면 왼쪽 위에 `D` 버튼이 생깁니다
- 기능: 돈 +1,000 / 복구 단계 +1 / 보드 초기화 / 아이템 생성(종류·단계) / 보드 가득 채우기 / FPS / 저장 지우고 새로 시작 / 이미지 상태

## 수치·문장 고치기

모든 수치와 화면 문장은 `src/data.js` 한 곳에 있습니다. 보드 크기, 단계 이름, 생성기 위치, 시작 재료, 길게 누르기 시간, 안내 문구 등.
보드 크기를 바꾸면 저장된 진행은 자동으로 버리고 새로 시작합니다.

## 이미지 넣기

1. 이미지를 `assets/<파일명>.png`로 저장합니다 (원본은 `assets/original/`)
2. `src/index.html`을 새로고침하면 바로 바뀝니다. 파일이 없으면 색 블록으로 나옵니다
3. 디버그 패널 "이미지 상태"에서 `[있음]`/`[없음]`을 확인합니다

| 파일명 | 내용 | 크기(px) |
| --- | --- | --- |
| `oden_1` ~ `oden_5` | 어묵 체인 1~5단계 | 256×256, 투명 |
| `gukbap_1` ~ `gukbap_5` | 돼지국밥 체인 1~5단계 | 256×256, 투명 |
| `gen_oden`, `gen_gukbap` | 생성기 | 256×256, 투명 |
| `ui_cell` | 보드 칸(쟁반) | 128×128, 투명 |
| `ui_board` | 보드 판(나무 카운터) | 1080×1200, 투명 |
| `ui_hud` | 상단 바 | 1080×112, 투명 |
| `ui_coin` | 돈 아이콘 | 96×96, 투명 |
| `fx_merge` | 합성 반짝 | 256×256, 투명 |
| `shop_0`, `shop_1`, `shop_2` | 가게 (낡음 / 1단계 / 2단계) | 1080×660 |

손님·인물·대화창 이미지(2~3일차)의 이름과 프롬프트는 `../오캉과엄마_아빠의기억_AI이미지_프롬프트_ComfyUI.md` 3장에 있습니다.

## 테스트

```bash
node tools/test.js
```

합성·생성기·삭제·시드 난수·저장 형식을 확인합니다 (화면·애니메이션은 대상 아님).

## 파일

| 파일 | 하는 일 |
| --- | --- |
| `src/data.js` | 모든 수치·문장·색·이미지 이름 |
| `src/rng.js` | 시드 난수 (mulberry32) |
| `src/board.js` | 머지 보드 규칙 (순수 계산) |
| `src/scene.js` | 장면 상태 (1일차에는 머지 장면만) |
| `src/ui.js` | 화면 그리기, 이미지 불러오기 |
| `src/debug.js` | 디버그 패널 |
| `src/main.js` | 시작, 저장, 입력(드래그/터치), 매 프레임 갱신 |
| `tools/test.js` | 자동 테스트 |
