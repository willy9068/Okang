### 만든 것
- 주문 칸 3개: 손님 얼굴(placeholder), 필요한 요리 1~2개, 보상. 보드에 있는 요리는 초록 ✓, 다 모이면 "내기 +돈"
- 요리를 주문 칸에 끌어 놓으면 하나씩 채움, 다 모였으면 주문 칸 탭으로 한꺼번에 내기
- 주문이 끝나면 돈이 HUD로 날아가고 새 주문(다른 손님)으로 바뀜
- 복구 버튼: 비용·모은 돈 막대, 탭하면 돈 차감 → 가게 그림 단계 교체(번쩍 연출) → 안내 문구
- 조작 안내 3문장 (생성기 → 합성 → 주문). 안내마다 따로 '해 봤음'을 표시
- 복구 2단계 뒤 "복구 완료! 걸린 시간 m:ss" 안내. 시간은 머지 장면에서 탭을 보고 있던 시간만 셈 (화면에 보여 줄 뿐, 따로 기록·내보내기는 하지 않음)
- 디버그 패널: 주문 새로 뽑기, 진행 정보 추가
- 저장 키 `abba_memory_v2` (주문·복구·안내 상태 포함. v1 저장은 새로 시작)
- 자동 테스트 48개, 밸런스 어림 `tools/balance.js`

### 첫 밸런스 (임시)
- 보상: 2단계 15 / 3단계 35 / 4단계 80 / 5단계 170 (단계가 하나 오르면 재료가 2배 드므로 약 2배)
- 복구 비용: **1단계 520, 2단계 780**
- `node tools/balance.js` 결과 (가상 플레이어 30판, 사람 보정 ×1.3): 복구 1단계까지 약 2분 55초(주문 약 15개), 2단계까지 약 4분 7초(주문 약 11개), 머지 합계 약 7분
- 가상 플레이어는 실수 없이 효율적으로 움직이므로 실제 사람은 더 오래 걸릴 가능성이 큽니다. **직접 해 본 시간으로 비용을 다시 맞춰야 합니다.**
- 질문에서는 "주문 5~6개"라고 어림했는데, 계산해 보니 3분이면 주문 약 15개가 나옵니다. 주문 수를 줄이고 싶으면 보상을 올리고 비용을 같이 올리면 됩니다.
