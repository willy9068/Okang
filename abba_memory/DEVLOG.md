### 만든 것
- 세로 9:16 화면, 창 크기에 맞춰 가운데 정렬 (PC·휴대폰)
- 머지 보드 7×9 (임시), 생성기 2개(어묵·돼지국밥), 시작 재료 4개
- 생성기 탭 → 가장 가까운 빈 칸에 1단계 (거리가 같으면 시드 난수)
- 드래그/터치 합성, 자리 바꿈, 끄는 동안 합칠 수 있는 칸 표시
- 보드 가득 참 → 안내 문구 + 생성기 흔들림
- 길게 눌러 삭제 (빨간 원 게이지), 생성기는 삭제 불가
- 아이템 탭 → 이름·다음 단계 안내
- localStorage 저장(버전 키 `abba_memory_v1`, 막혀도 동작)
- D키 디버그 패널
- 이미지 자리: 파일만 넣으면 교체, 없으면 색 블록
- 자동 테스트 27개 (`node tools/test.js`)
